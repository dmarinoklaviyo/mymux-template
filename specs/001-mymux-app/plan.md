# Implementation Plan: mymux — Multi-Session Claude Code Orchestrator

**Branch**: `001-mymux-app` | **Date**: 2026-06-29 | **Spec**: [spec.md](spec.md)  
**Input**: Feature specification from `/specs/001-mymux-app/spec.md`

## Summary

mymux is a native macOS desktop application that orchestrates multiple concurrent Claude Code terminal sessions into named "work tracks." The primary value is centralized, real-time observability — a single sidebar showing every session's state (active/thinking/waiting/suspended/completed) with OS notifications when any session needs attention. The full implementation covers: native terminal emulation via SwiftTerm, PTY output monitoring for state classification, 5 MCP tools delivered via a Node.js Unix-domain-socket server, an SQLite-backed persistence layer, git status polling, a supplemental shell panel, and session resume via `--continue` and named worktrees. All work is structured as a Swift Package Manager executable targeting macOS 14+ with no App Sandbox.

## Technical Context

**Language/Version**: Swift 5.9+ (SPM executable target targeting macOS 14+); TypeScript 5.0 for MCP server, compiled by esbuild to ESM  
**Primary Dependencies**: SwiftTerm ~>1.11 (terminal emulation), GRDB.swift ~>7.0 (SQLite ORM), AppKit (UI); Node.js 20+ + `@modelcontextprotocol/sdk` (MCP server)  
**Storage**: SQLite at `~/.mymux/mymux.db` managed via GRDB DatabasePool; no persistence for shell sessions or in-flight display status  
**Testing**: G1 `swift build` (no errors), G2 `swift run` (window visible), G3–G6 runtime verification in live app (see Quality Gates below); no XCTest unit tests in scope  
**Target Platform**: macOS 14 (Sonoma)+, Apple Silicon and Intel; no App Sandbox (PTY access required)  
**Project Type**: macOS desktop application (SPM `.executableTarget`)  
**Performance Goals**: ≥10 simultaneous terminal sessions; terminal input latency ≤16ms; status detection within 500ms of state change  
**Constraints**: No App Sandbox; Node.js 20+ and `claude` CLI must be installed on the machine at runtime; socket at `/tmp/mymux-ipc.sock`; MCP config files at `/tmp/mymux-mcp/`  
**Scale/Scope**: Single-user personal tool; 10–20 simultaneous sessions; single macOS process
